This application is built for Windows 11 (Version 25H2) and requires a minimum of 4 GB of RAM and 250 GB of available storage space.
1. Recommended Windows Configuration:

    - Computer Name: SERVER-PC (Suggested)
    - Username: ADMIN (Suggested; must have administrator privileges)
    - Password: [Required]

3. Assuming your Windows 11 is freshly installed.

4. Create database folder "MSSQL" in Drive C or D.
C:\>netsh advfirewall firewall set rule group="File and Printer Sharing" new enable=Yes
C:\>netsh advfirewall firewall add rule name="Open Port 1433" dir=in action=allow protocol=TCP localport=1433
The application requires the following software components listed below.

The programmer will be provided these files to you.
1. Open "1) Microsoft SQL Server 2025 Express Edition".

2. Double click setup.exe.
Installation of SQL Server Management Studio.
Configure SQL Server Accessibility.
1. At this point Restart your server.

2. Copy Initial Database files to SQL Server Data Folder.
Look for SQL Server Management Studio 22 in the Start Menu.
Done.
